Tutorial GitHub: do git init ao deploy

Um passo a passo direto para criar um repositório local, enviar o projeto para o GitHub e publicar uma landing page com GitHub Pages.

Você vai aprender:
  • Configurar nome e e-mail do Git
  • Inicializar um projeto com Git
  • Subir arquivos para o GitHub
  • Publicar o site na internet
Configuração Git init GitHub Push Deploy Fluxo diário
1

Configurar o Git no computador

Identifique seu usuário

Faça isso uma vez no computador para que seus commits tenham autor correto.

git config --global user.name "Seu Nome"
git config --global user.email "seu-email@exemplo.com"

Confira a configuração

Esses comandos mostram qual nome e e-mail serão usados nos commits.

git config user.name
git config user.email

Use o mesmo e-mail cadastrado no GitHub para facilitar a associação dos commits ao seu perfil.

2

Criar o repositório local

Entre na pasta do projeto

No terminal, navegue até a pasta onde está o seu index.html.

cd caminho/da/sua/pasta

Inicie o Git

O comando cria a pasta oculta .git, onde o histórico do projeto será guardado.

git init

Veja o estado dos arquivos

Mostra arquivos novos, modificados ou prontos para commit.

git status

Adicione os arquivos

Prepara todos os arquivos da pasta para o primeiro commit.

git add .

Crie o primeiro commit

O commit salva uma versão do projeto no histórico local.

git commit -m "Projeto inicial"
3

Criar o repositório no GitHub

  1. Acesse github.com e entre na sua conta.
  2. Clique em New repository.
  3. Digite o nome do repositório, por exemplo minha-landing-page.
  4. Escolha Public se quiser usar GitHub Pages sem restrições.
  5. Não marque README, .gitignore ou license se o projeto já existe no computador.
  6. Clique em Create repository.

Depois de criar o repositório, copie a URL HTTPS mostrada pelo GitHub. Ela será parecida com https://github.com/seu-usuario/minha-landing-page.git.

4

Conectar e enviar para o GitHub

Renomeie a branch principal

O padrão mais usado atualmente é chamar a branch principal de main.

git branch -M main

Adicione o repositório remoto

Troque a URL pelo link do seu repositório no GitHub.

git remote add origin https://github.com/seu-usuario/minha-landing-page.git

Confira o remoto

Verifique se o Git está apontando para o lugar certo.

git remote -v

Envie o projeto

O -u conecta sua branch local com a branch remota para facilitar os próximos pushes.

git push -u origin main
5

Fazer deploy com GitHub Pages

Para uma página estática com index.html, o jeito mais simples é publicar pelo próprio GitHub Pages.

  1. No GitHub, abra o repositório do projeto.
  2. Entre em Settings.
  3. No menu lateral, clique em Pages.
  4. Em Build and deployment, escolha Deploy from a branch.
  5. Em Branch, selecione main e a pasta /root.
  6. Clique em Save.

Depois de alguns minutos, o GitHub vai mostrar o link publicado. Normalmente ele fica no formato https://seu-usuario.github.io/nome-do-repositorio/.

6

Fluxo para atualizar o site depois

Sempre que editar o projeto, use este ciclo para salvar e publicar as mudanças:

git status
git add .
git commit -m "Descreva a alteração"
git push
1. Editou arquivos: altere HTML, CSS, imagens ou scripts normalmente.
2. Fez commit: salvou uma versão local com uma mensagem clara.
3. Fez push: enviou a versão para o GitHub.
4. GitHub Pages atualizou: o deploy acontece automaticamente após o push.
Tutorial prático para publicar projetos HTML no GitHub.
