Um passo a passo direto para criar um repositório local, enviar seu projeto para o GitHub e publicar uma landing page na internet — do zero ao ar.

6 etapas do repositório local ao site no ar
⚙️ Configuração 📁 Git init 🐙 GitHub 🚀 Push 🌐 Deploy 🔄 Fluxo diário
1

Configurar o Git no computador

Identifique seu usuário

Faça isso uma vez no computador para que seus commits tenham o autor correto.

git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

Confira a configuração

Esses comandos mostram qual nome e e-mail serão usados nos commits.

git config user.name
git config user.email

Use o mesmo e-mail cadastrado no GitHub para associar os commits ao seu perfil automaticamente.

2

Criar o repositório local

Entre na pasta do projeto

No terminal, navegue até a pasta onde está o seu index.html.

cd caminho/da/sua/pasta

Inicie o Git

Cria a pasta oculta .git onde o histórico do projeto será guardado.

git init

Veja o estado dos arquivos

Mostra arquivos novos, modificados ou prontos para commit.

git status

Adicione os arquivos

Prepara todos os arquivos da pasta para o primeiro commit.

git add .

Crie o primeiro commit

O commit salva uma versão do projeto no histórico local com uma mensagem descritiva.

git commit -m "Projeto inicial"
3

Criar o repositório no GitHub

  1. Acesse github.com e entre na sua conta.
  2. Clique em New repository.
  3. Digite o nome, por exemplo minha-landing-page.
  4. Escolha Public se quiser usar GitHub Pages sem restrições.
  5. Não marque README, .gitignore ou license — o projeto já existe no seu computador.
  6. Clique em Create repository.

Depois de criar o repositório, copie a URL HTTPS exibida pelo GitHub — algo como https://github.com/seu-usuario/minha-landing-page.git.

4

Conectar e enviar para o GitHub

Renomeie a branch principal

O padrão mais usado atualmente é main.

git branch -M main

Adicione o repositório remoto

Substitua a URL pelo link do seu repositório no GitHub.

git remote add origin https://github.com/seu-usuario/minha-landing-page.git

Confira o remoto

Verifique se o Git está apontando para o lugar certo.

git remote -v

Envie o projeto

O -u conecta sua branch local com a remota para facilitar próximos pushes.

git push -u origin main
5

Fazer deploy com GitHub Pages

Para uma página estática com index.html, o jeito mais simples é publicar pelo GitHub Pages diretamente.

  1. No GitHub, abra o repositório do projeto.
  2. Entre em Settings.
  3. No menu lateral, clique em Pages.
  4. Em Build and deployment, escolha Deploy from a branch.
  5. Em Branch, selecione main e a pasta /root.
  6. Clique em Save.

Depois de alguns minutos, o GitHub exibe o link publicado — normalmente no formato https://seu-usuario.github.io/nome-do-repositorio/.

6

Fluxo para atualizar o site

Sempre que editar o projeto, use este ciclo para salvar e publicar as mudanças:

git status
git add .
git commit -m "Descreva a alteração"
git push
1

Editou arquivos — altere HTML, CSS, imagens ou scripts normalmente.

2

Fez commit — salvou uma versão local com uma mensagem clara.

3

Fez push — enviou a versão para o repositório no GitHub.

4

GitHub Pages atualizou — o deploy acontece automaticamente após o push.
